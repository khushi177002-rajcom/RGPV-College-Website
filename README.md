
# RGPV College Website

## About the Project
This project is a multi-page college website created for Rajiv Gandhi Proudyogiki Vishwavidyalaya (RGPV), Bhopal.

The website provides information about the university, its departments, courses, faculty and student activities.

## Technologies Used
- HTML5

## Website Pages
1. Home Page
2. About College
3. Academics
4. Students
5. Timetable and Marks
6. Contact

## Features
- College introduction
- RGPV campus image
- About college information
- Departments and courses
- Faculty information
- Student achievements and projects
- Weekly timetable
- Student marks table
- Contact form
- Registration form
- Feedback form

## Project Folder Structure

RGPV-College-Website/

- academics.html
- students.html
- timetable.html
- contact.html
- README.md
- images/
  - rgpv-campus.jpg

## Image Information
The RGPV campus image is stored in the images folder and displayed using an HTML relative file path.

## How to Run the Project
1. Download or clone the project.
2. Open the project folder.
3. Open index.html in a web browser.
4. Use the navigation links to explore all pages.
